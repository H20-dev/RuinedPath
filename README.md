# 残途 | Ruined Path
一款末世题材 **文字冒险独立游戏**，控制台纯文字玩法。

## 内容
- 控制台特色特效
- 30 坏结局 终局-憾恨
- 10 好结局 终局-幸悦
- 10 真相 终局-真章
- 25 线索 线索-星光
- 5 主线剧情
- 4 支线剧情
- 周目继承特色
- 存档读档系统
- Meta 元素

## 操作说明
- ↑ ↓ 方向键：切换选项
- 回车键 / 数字键：确认选择
- F 键：快进文本

## 运行方式
- 仅支持 Windows 10+ 系统
- Windows 11 + Windows Terminal 以获得最佳体验
- 直接打开 / 编译 RuinedPath.exe 即可
