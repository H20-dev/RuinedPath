# RuinedPath
A post-apocalyptic zombie text survival game. Explore on your own, infinite possibilities.

# 残途 | Ruined Path

一款末世丧尸题材 **文字生存冒险游戏**，控制台纯文字玩法、海量分支结局。

## 游戏特色
- 自行探索，无限可能

## 操作说明
- ↑ ↓ 方向键：切换选项
- 回车键 / 数字键：确认选择

## 运行方式
仅支持 Windows 系统
解压后直接双击 RuinedPath.exe 即可游玩
无需安装，无需额外运行库，单文件版
